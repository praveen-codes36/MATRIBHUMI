## 🇮🇳 Why MATRIBHUMI

**मातृभूमि** means *motherland*, the place you come from and the place you owe something back to.

India has millions of problems, and millions of young minds. MATRIBHUMI starts from one belief:

```text
Someone has a problem.
Someone needs a solution.
And maybe... we can build it.
```

It is a project built **for people**, **with purpose**, and **for the future**, not for marks or a portfolio.

## 🚀 Run Locally

```bash
# 1. Clone
git clone https://github.com/praveen-codes36/MATRIBHUMI.git
cd MATRIBHUMI

# 2. Backend
cd Backend
npm install
cp .env.example .env     # then fill in your values
npm run dev

# 3. Frontend (new terminal)
cd frontend
npm install
npm run dev
```
